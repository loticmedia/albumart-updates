AlbumArt: open-source notices
=============================

The AlbumArt firmware is Lotic Media's own and is not open source. It is built
with the open-source software listed below, each used under the licence
reproduced here, as those licences ask. The device serves this text at
http://<its address>/licenses, and each release publishes it beside the
firmware image.

This file is generated from the firmware image's linker map by
tools/release/gen_notices.py; edit tools/release/notices_map.json rather than
this file.
